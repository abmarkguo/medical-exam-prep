# 备考计划模板 (Study Plan Templates)

## 1. 六个月综合备考计划

### 适用对象
- 首次参加医师资格考试的考生
- 全职或半职备考，每天可学习3-4小时

### 阶段划分

| 阶段 | 时间 | 重点 | 目标 |
|------|------|------|------|
| 第一阶段：基础筑底 | 第1-2月 | 基础医学+医学人文 | 建立知识框架 |
| 第二阶段：临床攻坚 | 第3-4月 | 临床医学综合(75%) | 掌握核心疾病 |
| 第三阶段：技能突破 | 第5月 | 实践技能三站 | 技能考试通过 |
| 第四阶段：笔试冲刺 | 第6月 | 刷题+查漏补缺 | 笔试通过 |

### 第一阶段：基础筑底（第1-2月）

**第1-2周：生理学+生物化学**
| 内容 | 学习方法 | 每日时长 |
|------|----------|----------|
| 生理学各系统 | 教材+网课+笔记 | 3h |
| 生物化学代谢途径 | 图表记忆+口诀 | 2h |
| 每日练习题 | 30题A1型 | 1h |

**第3-4周：病理学+药理学**
| 内容 | 学习方法 |
|------|----------|
| 病理学总论+各论 | 病理图片+机制理解 |
| 药理学各系统 | 药物分类+副作用对比 |
| 每日练习题 | 30题A1+A2型 |

**第5-6周：微生物+免疫+预防医学**
| 内容 | 学习方法 |
|------|----------|
| 微生物学常见病原 | 表格对比记忆 |
| 免疫学基础 | 概念理解为主 |
| 预防医学+统计学 | 公式记忆+计算练习 |

**第7-8周：医学人文+中医学基础**
| 内容 | 学习方法 |
|------|----------|
| 医学伦理学（2026修订） | 案例分析为主 |
| 医学心理学 | 概念+应用 |
| 卫生法规（2026修订） | 法条记忆+案例 |
| 中医学基础 | 概念入门，不需深究 |

### 第二阶段：临床攻坚（第3-4月）

**第9-10周：内科-心血管+呼吸**
| 系统 | 高频疾病 | 学习重点 |
|------|----------|----------|
| 心血管 | 心衰、高血压、冠心病、心律失常 | 心电图判读+药物治疗 |
| 呼吸 | COPD、肺炎、哮喘、肺结核 | 肺功能+影像学 |

**第11-12周：内科-消化+泌尿+内分泌**
| 系统 | 高频疾病 | 学习重点 |
|------|----------|----------|
| 消化 | 溃疡、肝硬化、胰腺炎 | 胃镜+肝功能 |
| 泌尿 | 肾炎、肾病综合征、肾衰 | 尿检+肾功能 |
| 内分泌 | 糖尿病、甲亢 | 激素水平+并发症 |

**第13-14周：内科-血液+风湿+神经+精神+传染病**
| 系统 | 高频疾病 |
|------|----------|
| 血液 | 贫血、白血病、淋巴瘤 |
| 风湿 | SLE、类风湿 |
| 神经 | 脑血管病、癫痫 |
| 精神 | 抑郁症、精神分裂症 |
| 传染病 | 肝炎、艾滋病、伤寒 |

**第15-16周：外科+妇产+儿科**
| 科目 | 重点 |
|------|------|
| 外科 | 阑尾炎、胆石症、骨折、肠梗阻 |
| 妇产 | 妊高征、产后出血、妇科肿瘤 |
| 儿科 | 新生儿黄疸、小儿肺炎、腹泻病 |

### 第三阶段：技能突破（第5月）

| 周 | 内容 | 方法 |
|----|------|------|
| 第1周 | 第一站：病史采集+病例分析 | 模板背诵+模拟练习 |
| 第2周 | 第二站：体格检查 | 视频学习+实操练习 |
| 第3周 | 第二站：基本操作 | 无菌术+各项操作练习 |
| 第4周 | 第三站：多媒体+全真模拟 | 心电图/影像/听诊专项 |

### 第四阶段：笔试冲刺（第6月）

| 周 | 内容 | 方法 |
|----|------|------|
| 第1周 | 历年真题（近5年） | 限时模拟+错题分析 |
| 第2周 | 高频考点回顾 | 错题本复习+知识盲区 |
| 第3周 | 模拟试卷（3-5套） | 全真模拟+查漏补缺 |
| 第4周 | 考前调整 | 重点回顾+心态调整 |

|------|------|------|

## 3. 一个月冲刺计划

### 适用对象
- 已有较好基础的考生
- 考前最后冲刺

### 每日安排

| 时间段 | 内容 | 时长 |
|--------|------|------|
| 上午 | 高频考点复习（按系统） | 3h |
| 下午 | 真题/模拟题练习 | 3h |
| 晚上 | 错题分析+薄弱环节强化 | 2h |

### 每周安排

| 天数 | 重点系统 |
|------|----------|
| 第1-2天 | 心血管+呼吸 |
| 第3-4天 | 消化+泌尿+内分泌 |
| 第5天 | 血液+神经+传染 |
| 第6天 | 外科+妇产+儿科 |
| 第7天 | 基础+人文+模考 |

## 5. 个性化计划生成

根据以下信息生成个性化计划：

### 输入参数
- 考试类型：执业医师 / 助理医师
- 考试日期：____年__月__日
- 当前日期：____年__月__日
- 每日可学习时长：___小时
- 薄弱科目：________
- 强项科目：________
- 是否已通过技能考试：是/否

### 生成原则
1. **优先攻克高分值科目**：内科(32%) > 外科(23%) > 儿科(10.5%) > 妇产(9.5%)
2. **薄弱科目多分配时间**：但不超过总时间的30%
3. **定期模拟测试**：每2周一次，检验复习效果
4. **留出弹性时间**：每周留1天处理积压/调整进度
5. **考前2周以刷题和回顾为主**：不再学新内容

### 计划模板示例

```
个性化备考计划

考试日期：2026年8月21日
当前日期：2026年5月1日
剩余天数：112天
每日学习时长：4小时
总可用学习时长：448小时

时间分配：
- 临床医学综合：60%（269小时）
- 基础医学综合：20%（90小时）
- 医学人文综合：10%（45小时）
- 预防医学+中医：5%（22小时）
- 模拟测试+错题：5%（22小时）

阶段划分：
1. 第1-6周（42天）：临床医学综合系统学习
2. 第7-8周（14天）：基础医学+人文+预防
3. 第9-10周（14天）：技能考试准备
4. 第11-14周（28天）：刷题冲刺+模考
5. 最后2周：高频考点+错题+心态调整
```
