# 医师资格考试制度总览 (Exam System Overview)

## 1. 法律依据

医师资格考试依据《中华人民共和国医师法》（2022年3月1日施行）设立，是国家法定的医师准入考试。

- 主管部门：国家卫生健康委员会（临床、口腔、公共卫生类别）、国家中医药管理局（中医类别）
- 实施机构：国家医学考试中心（nmec.org.cn）
- 考试性质：国家级准入考试，非水平考试

## 2. 考试类别

### 2.1 执业级别

| 级别 | 考试 | 报考条件 |
|------|------|----------|
| 执业医师 | 技能+笔试 | 本科及以上学历，试用期满1年 |
| 执业助理医师 | 技能+笔试 | 专科及以上学历，试用期满1年 |

### 2.2 专业类别

| 类别 | 主管部门 | 笔试题量 | 合格线 |
|------|----------|----------|--------|
| 临床 | 国家卫健委 | 600(执业)/300(助理) | 360/180 |
| 口腔 | 国家卫健委 | 600/300 | 360/180 |
| 公共卫生 | 国家卫健委 | 600/300 | 360/180 |
| 中医 | 国家中医药管理局 | 600/300 | 360/180 |
| 中西医结合 | 国家中医药管理局 | 600/300 | 360/180 |
| 乡村全科执业助理 | 国家卫健委 | 300 | 180 |

> **本Skill聚焦临床类别**

## 3. 考试流程

```
网上报名(1月) → 现场审核(2-3月) → 实践技能考试(6月)
    ↓ 技能合格(60分)
医学综合笔试一试(8月) → 成绩公布(9月)
    ↓ 未通过
医学综合笔试二试(11月，部分地区)
```

## 4. 实践技能考试

### 4.1 基本信息汇总

| 项目 | 内容 |
|------|------|
| 总分 | 100分 |
| 合格线 | 60分 |
| 成绩有效期 | 2年（国家技能基地考试） |
| 考试形式 | 多站式 |

### 4.2 临床类别三站式

**第一站：临床思维（40分）**
- 病史采集（15分）：给定主诉，规范书写完整病史
- 病例分析（25分）：给定完整病例，做出诊断、鉴别诊断、治疗计划

**第二站：体格检查+基本操作（30分）**
- 体格检查（15分）：系统查体（心脏、肺部、腹部、神经系统等）
- 基本操作（15分）：无菌术、缝合、穿刺、导尿、CPR等

**第三站：多媒体机考（30分）**
- 心肺听诊（8分）
- 影像诊断（6分）：X线、CT
- 心电图判读（7分）
- 医德医风（9分）

## 5. 医学综合笔试

### 5.1 基本信息汇总

| 项目 | 执业医师 | 助理医师 |
|------|----------|----------|
| 总题量 | 600题 | 300题 |
| 总分 | 600分 | 300分 |
| 合格线 | 360分 | 180分 |
| 考试单元 | 4个单元 | 2个单元 |
| 每单元题量 | 150题 | 150题 |
| 每单元时长 | 2小时 | 2小时 |
| 考试形式 | 计算机化考试(CBT) | 计算机化考试(CBT) |
| 题型 | A1/A2/A3/A4/B1 | A1/A2/A3/A4/B1 |

### 5.2 四单元内容分布（临床执业医师）

| 单元 | 主要内容 | 题型侧重 |
|------|----------|----------|
| 第一单元 | 基础医学、医学人文、预防医学、中医学基础 | A1为主 + B1 |
| 第二单元 | 呼吸、循环、泌尿、运动系统 | A1 + A2 + A3/A4 |
| 第三单元 | 消化、血液、内分泌、传染病、风湿 | A2 + A3/A4 |
| 第四单元 | 妇产、儿科、神经、精神 | A2 + A3/A4最多 |

### 5.3 学科分值占比

| 学科类别 | 占比 | 主要学科 |
|----------|------|----------|
| 临床医学综合 | ~75% | 内科(32%)、外科(23%)、妇产(9.5%)、儿科(10.5%) |
| 基础医学综合 | ~15% | 生理、生化、病理、药理、微生物、免疫 |
| 医学人文综合 | ~10% | 伦理学、心理学、卫生法规(2026修订) |
| 预防医学综合 | 含于上述 | 预防医学、公共卫生 |
| 中医学基础 | 新增 | 中医基础理论 |

## 6. 通过率数据

| 考试环节 | 通过率 |
|----------|--------|
| 实践技能考试 | ~70% |
| 医学综合笔试 | ~18-22% |
| 综合通过率 | ~25% |

## 7. 2026年重要变化

1. **医学人文大纲修订**：新增医学史、中国医学传统道德、中医药法
2. **技能考试全面基地化**：统一评分、全程录像
3. **机考全面推行**：跨题型不可回看
4. **一年两试扩大**：临床、中医类别更多地区开放
5. **第十版教材启用**：考点变动超20%

## 8. 成绩管理

- 实践技能成绩：国家技能基地合格成绩2年有效
- 医学综合笔试：当年有效，不设单科合格线，总分达标即可
- 合格证明：电子化注册，无需纸质证书
