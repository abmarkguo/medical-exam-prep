# 高频考点速查 (High-Frequency Exam Points)

> 按系统分类的历年高频考点，按出题频率排序

## 1. 心血管系统

### 1.1 心力衰竭
| 考点 | 要点 |
|------|------|
| NYHA分级 | I-IV级，IV级最重（休息时症状） |
| 射血分数分类 | HFrEF(EF<40%)、HFmrEF(40-49%)、HFpEF(≥50%) |
| 慢性心衰药物 | ACEI/ARB + β受体阻滞剂 + 醛固酮拮抗剂 + SGLT2抑制剂（新四联） |
| 急性左心衰 | 端坐呼吸、粉红色泡沫痰、双肺湿啰音 → 坐位、吸氧、利尿、扩血管、强心 |
| 洋地黄中毒 | 室性早搏二联律、黄视绿视 → 停药、补钾、苯妥英钠 |

### 1.2 高血压
| 考点 | 要点 |
|------|------|
| 分级标准 | 1级(140-159/90-99)、2级(160-179/100-109)、3级(≥180/110) |
| 危险分层 | 低危/中危/高危/很高危（靶器官损害+并发症决定） |
| 首选药物 | 糖尿病/肾病→ACEI/ARB；老年人→CCB；心衰→ACEI+β阻滞剂 |
| 高血压急症 | 舒张压>130mmHg + 急性靶器官损害 → 静脉降压（硝普钠/硝酸甘油） |

### 1.3 冠心病
| 考点 | 要点 |
|------|------|
| 心绞痛 vs 心梗 | 硝酸甘油缓解→心绞痛；不缓解→心梗 |
| STEMI心电图 | ST段弓背向上抬高 + 病理性Q波 |
| 心肌标志物 | cTnI/cTnT（金标准，3-4h升高）、CK-MB（早期再灌注指标） |
| 急性心梗治疗 | 再灌注（PCI<12h / 溶栓<12h）+ 双抗 + 他汀 + ACEI + β阻滞剂 |
| 心梗并发症 | 心律失常（24h内最常见死因）、乳头肌断裂、室间隔穿孔、心室壁瘤 |

### 1.4 心律失常
| 考点 | 要点 |
|------|------|
| 房颤 | 无P波+f波+RR不齐 → 抗凝（CHA2DS2-VASc评分）+ 控制心室率 |
| 室速 | 宽QRS波+房室分离 → 利多卡因/胺碘酮 → 无脉→电除颤 |
| 室颤 | 波形杂乱 → 立即非同步电除颤 |
| 一度AVB | PR>0.20s → 无需治疗 |
| 三度AVB | P与QRS无关 → 临时/永久起搏器 |

## 2. 呼吸系统

### 2.1 COPD
| 考点 | 要点 |
|------|------|
| 诊断 | 吸烟史+咳痰喘+肺功能FEV1/FVC<70% |
| GOLD分级 | 基于FEV1占预计值百分比（1-4级） |
| 稳定期治疗 | 支气管扩张剂(LABA/LAMA)为主 + ICS(重度) |
| 急性加重 | 抗生素+激素+支气管扩张剂+氧疗（低流量吸氧） |
| 并发症 | 慢性呼衰、肺心病、气胸 |

### 2.2 肺炎
| 类型 | 病原体 | 特征 | 首选药 |
|------|--------|------|--------|
| 大叶性 | 肺炎链球菌 | 铁锈色痰 | 青霉素 |
| 小叶性 | 肺炎链球菌等 | 黄脓痰 | 青霉素/头孢 |
| 间质性 | 支原体/衣原体 | 干咳+冷凝集试验+ | 大环内酯类 |
| 真菌性 | 念珠菌/曲霉菌 | 免疫低下者 | 氟康唑 |

### 2.3 哮喘
| 考点 | 要点 |
|------|------|
| 诊断 | 反复发作喘息+可逆性气流受限(支气管舒张试验+) |
| 长期控制 | ICS+LABA（吸入糖皮质激素+长效β2激动剂） |
| 急性发作 | SABA(沙丁胺醇)+全身激素+氧疗 |
| 重度哮喘 | 嗜酸性粒细胞增高→生物靶向治疗 |

### 2.4 肺结核
| 考点 | 要点 |
|------|------|
| 分型 | 原发性、血行播散型、继发性（浸润性最常见） |
| 诊断 | 痰涂片抗酸杆菌(金标准)、PPD试验、胸片 |
| 治疗原则 | 早期、联合、适量、规律、全程 |
| 标准方案 | 2HRZE/4HR（强化期2月+巩固期4月） |
| 副作用监测 | 异烟肼→肝损/周围神经炎；利福平→肝损/体液橙红；乙胺丁醇→视神经炎；吡嗪酰胺→高尿酸 |

## 3. 消化系统

### 3.1 消化性溃疡
| 考点 | 要点 |
|------|------|
| 胃溃疡 vs 十二指肠溃疡 | GU：餐后痛；DU：饥饿痛、夜间痛 |
| 并发症 | 出血（最常见）、穿孔、幽门梗阻、癌变 |
| Hp检测 | C13/C14呼气试验（非侵入性首选） |
| Hp根除 | 四联：PPI+铋剂+阿莫西林+克拉霉素，14天 |
| 手术指征 | 急性穿孔、大出血内科无效、瘢痕性幽门梗阻、癌变 |

### 3.2 肝硬化
| 考点 | 要点 |
|------|------|
| 病因 | 我国以病毒性肝炎（乙肝）为主 |
| 失代偿表现 | 肝功能减退+门脉高压（腹水、食管胃底静脉曲张、脾大） |
| 腹水治疗 | 限钠+利尿(螺内酯+呋塞米)±TIPS |
| 食管胃底静脉曲张出血 | 生长抑素+三腔二囊管+内镜治疗 |
| 肝性脑病 | 诱因(消化道出血/感染/高蛋白)→降氨(乳果糖)+支链氨基酸 |

### 3.3 急性胰腺炎
| 考点 | 要点 |
|------|------|
| 病因 | 胆道疾病（我国最常见）、酒精、高脂血症 |
| 诊断标准 | 淀粉酶/脂肪酶升高3倍以上+影像学 |
| Ranson评分 | 评估严重程度 |
| 治疗 | 禁食胃肠减压+补液+抑酸抑酶+镇痛（哌替啶） |
| 重症胰腺炎 | 出血坏死→抗生素+ICU+手术清创 |

## 4. 泌尿系统

### 4.1 肾小球肾炎
| 类型 | 特征 | 治疗 |
|------|------|------|
| 急性肾炎 | 链球菌感染后+血尿+补体C3降低 | 休息+对症 |
| 慢性肾炎 | 蛋白尿+血尿+水肿+高血压+肾功能减退 | ACEI/ARB+控压 |
| 肾病综合征 | 大量蛋白尿(>3.5g/d)+低白蛋白(<30g/L) | 激素+免疫抑制剂 |

### 4.2 慢性肾衰竭
| 考点 | 要点 |
|------|------|
| 分期 | 基于eGFR：G1-G5期，G5(ESRD)需替代治疗 |
| 并发症 | 贫血(促红素不足)、高钾血症、代谢性酸中毒、肾性骨病 |
| 透析指征 | eGFR<10或出现尿毒症症状、严重高钾、容量超负荷 |

## 5. 内分泌系统

### 5.1 糖尿病
| 考点 | 要点 |
|------|------|
| 诊断标准 | 空腹≥7.0、OGTT 2h≥11.1、随机≥11.1+症状 |
| 分型 | 1型(自身免疫)、2型(胰岛素抵抗)、GDM(妊娠糖尿病) |
| 治疗阶梯 | 生活方式→二甲双胍→加用SGLT2i/SU/DPP-4i/GLP-1→胰岛素 |
| 并发症 | 急性：DKA、HHS；慢性：微血管(肾/视网膜/神经)、大血管(心/脑/外周) |
| DKA治疗 | 补液(首选)+小剂量胰岛素+补钾+纠酸(慎用) |

### 5.2 甲状腺疾病
| 疾病 | 诊断要点 | 治疗 |
|------|----------|------|
| Graves病 | 甲亢症状+弥漫性甲状腺肿+TRAb阳性 | 抗甲药/碘131/手术 |
| 甲减 | TSH升高+FT4降低 | 左甲状腺素替代 |
| 亚急性甲状腺炎 | 上感史+甲状腺疼痛+ESR增快 | 激素(对症) |
| 甲状腺危象 | 高热+心率>160+精神症状 | PTU+碘剂+β阻滞剂+激素 |

## 6. 血液系统

### 6.1 贫血
| 类型 | MCV | 常见疾病 | 治疗 |
|------|------|----------|------|
| 小细胞低色素 | <80 | 缺铁性贫血、地中海贫血 | 补铁 |
| 正细胞 | 80-100 | 再生障碍性贫血、急性失血 | 病因治疗 |
| 大细胞 | >100 | 巨幼细胞贫血 | 补叶酸/B12 |

### 6.2 白血病
| 类型 | 特征 | 治疗 |
|------|------|------|
| 急性髓系 | Auer小体、POX阳性 | 化疗(7+3方案) |
| 急性淋巴 | PAS阳性 | VDLP方案 |
| 慢性髓系 | Ph染色体/BCR-ABL | 靶向(伊马替尼) |
| 慢性淋巴 | 淋巴细胞增多 | 观察或化疗 |

## 7. 女性生殖系统

### 7.1 产科高频
| 疾病 | 诊断要点 | 处理 |
|------|----------|------|
| 妊娠期高血压 | BP≥140/90+蛋白尿 | 硫酸镁解痉+降压+适时终止 |
| 子痫 | 抽搐发作 | 硫酸镁+镇静+控压+终止妊娠 |
| 前置胎盘 | 无痛性阴道出血 | 期待/终止妊娠，禁肛查 |
| 胎盘早剥 | 有痛性阴道出血+子宫板样硬 | 及时终止妊娠 |
| 产后出血 | 胎儿娩出后24h内>500ml | 按摩子宫+缩宫素+压迫+介入 |

### 7.2 妇科高频
| 疾病 | 诊断要点 | 处理 |
|------|----------|------|
| 子宫肌瘤 | 月经增多+子宫增大 | 观察/手术 |
| 宫颈癌 | 接触性出血+HPV感染 | TCT+HPV筛查→活检确诊 |
| 卵巢肿瘤 | 腹块+影像学 | 肿瘤标志物+手术 |
| 异位妊娠 | 停经+腹痛+阴道出血+HCG阳性 | 手术/保守 |

## 8. 儿科

### 8.1 高频疾病
| 疾病 | 诊断要点 | 治疗 |
|------|----------|------|
| 新生儿黄疸 | 胆红素>生理范围 | 光疗/换血 |
| 维D缺乏性佝偻病 | 夜惊+枕秃+骨骼改变 | 补维D+钙 |
| 小儿肺炎 | 发热+咳嗽+呼吸困难+肺部啰音 | 抗生素+对症 |
| 小儿腹泻 | 大便次数增多+脱水评估 | ORS/静脉补液+锌 |
| 手足口病 | 手/足/口疱疹+发热 | 对症+重症识别 |

## 9. 传染病

| 疾病 | 传播途径 | 诊断要点 | 隔离方式 |
|------|----------|----------|----------|
| 病毒性肝炎 | 血源/消化道(甲戊) | 肝功能+肝炎标志物 | 甲戊：消化道隔离 |
| 艾滋病 | 血源/性/母婴 | HIV抗体+CD4 | 不需隔离 |
| 伤寒 | 消化道 | 持续高热+玫瑰疹+肥达反应 | 消化道隔离 |
| 细菌性痢疾 | 消化道 | 腹痛+里急后重+黏液脓血便 | 消化道隔离 |
| 肾综合征出血热 | 鼠类 | 三红三痛+少尿+异形淋巴细胞 | 接触隔离 |

## 10. 基础医学高频

### 10.1 药理学速记
| 药物类别 | 代表药 | 关键考点 |
|----------|--------|----------|
| β受体阻滞剂 | 普萘洛尔 | 禁忌：哮喘、心衰失代偿 |
| ACEI | 依那普利 | 副作用：干咳、高钾 |
| 利尿剂 | 呋塞米 | 副作用：低钾、耳毒性 |
| 洋地黄 | 地高辛 | 中毒：室早二联律、黄视 |
| 氨基糖苷类 | 庆大霉素 | 副作用：肾毒性、耳毒性 |
| 大环内酯类 | 红霉素 | 副作用：胃肠道反应 |
| 喹诺酮类 | 环丙沙星 | 禁忌：儿童、孕妇 |

### 10.2 病理学速记
| 病理改变 | 疾病 |
|----------|------|
| 干酪样坏死 | 结核 |
| 凝固性坏死 | 心梗 |
| 液化性坏死 | 脑梗死 |
| 纤维素样坏死 | 风湿病、SLE |
| 鳞状细胞癌 | 食管癌、宫颈癌 |
| 腺癌 | 胃癌、结直肠癌 |
| 小细胞癌 | 肺癌(燕麦细胞癌) |
