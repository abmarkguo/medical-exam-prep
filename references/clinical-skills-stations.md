# 实践技能考试三站详解 (Clinical Skills Exam Stations)

> 临床类别实践技能考试：总分100分，合格60分，三站式考核

## 1. 总体安排

| 项目 | 内容 |
|------|------|
| 总分 | 100分 |
| 合格线 | 60分 |
| 考试时长 | 约65分钟（各站时间不同） |
| 考试地点 | 国家实践技能考试基地 |
| 成绩有效期 | 2年 |
| 考试形式 | 多站式，全程录像 |

## 2. 第一站：临床思维（40分）

### 2.1 考试形式
- 机考答题，纸笔作答
- 考试时长：约26分钟
- 分两部分：病史采集（15分）+ 病例分析（25分）

### 2.2 病史采集（15分）

**考试方式**：给定主诉，要求书写完整病史

**评分标准（15分制）**：

| 项目 | 分值 | 要求 |
|------|------|------|
| 一般项目 | 0.5分 | 姓名、性别、年龄、职业等 |
| 主诉 | 1分 | 主要症状+持续时间，简明扼要 |
| 现病史 | 7分 | 起病情况、主要症状特点、伴随症状、病情演变、诊疗经过、一般情况 |
| 既往史 | 2分 | 既往疾病史、手术外伤史、输血史、过敏史 |
| 个人史 | 1分 | 出生地、疫区居住、职业暴露、生活习惯 |
| 婚育史 | 1分 | 婚姻、生育情况（女性必问月经史） |
| 家族史 | 1分 | 家族遗传病、类似疾病史 |
| 问诊技巧 | 1.5分 | 条理性、逻辑性、专业用语、态度 |

**现病史七要素**（核心7分）：
1. 起病情况与患病时间（1分）
2. 主要症状特点（部位、性质、程度、诱因、加重/缓解因素）（2分）
3. 病情的发展与演变（1分）
4. 伴随症状（1分）
5. 诊疗经过（是否就医、用药、效果）（1分）
6. 一般情况（精神、睡眠、饮食、大小便、体重）（1分）
7. 阴性鉴别症状（有鉴别诊断意义的阴性症状）（0分-附加分）

**病史采集模板**：
```
一、一般项目
姓名/性别/年龄/民族/婚姻/职业/籍贯/入院日期

二、主诉
[主要症状] [持续时间]（不超过20字）

三、现病史
1. 起病情况与患病时间：何时起病，急/缓，可能诱因
2. 主要症状特点：部位、性质、程度、持续时间、加重/缓解因素
3. 病情演变：加重或缓解，频率变化
4. 伴随症状：有无其他不适（按系统询问相关阴性症状）
5. 诊疗经过：是否就诊，诊断/治疗，用药及效果
6. 一般情况：精神、睡眠、食欲、大小便、体重变化

四、既往史
既往疾病史、传染病史、手术外伤史、输血史、过敏史、预防接种史

五、个人史
出生地、疫区居住史、职业史、生活习惯（烟酒）、冶游史

六、婚育史
婚姻状况、配偶健康、生育情况
女性：月经史（初潮年龄/周期/经期/末次月经）

七、家族史
父母/兄弟姐妹健康状况，家族遗传病/类似疾病史
```

### 2.3 病例分析（25分）

**考试方式**：给定完整病例（病史+查体+辅助检查），要求做出诊断及分析

**评分标准（25分制）**：

| 项目 | 分值 | 要求 |
|------|------|------|
| 诊断 | 8分 | 主诊断+并发症/合并症，完整准确 |
| 诊断依据 | 6分 | 从病史、体征、辅助检查三方面论证 |
| 鉴别诊断 | 5分 | 至少2-3个，说明鉴别要点 |
| 进一步检查 | 3分 | 为确诊/排除鉴别诊断所需的检查 |
| 治疗原则 | 3分 | 一般治疗、药物治疗、手术治疗等 |

**病例分析模板**：
```
一、诊断（8分）
1. [主诊断]（需含部位、性质、分期/分度）
2. [并发症/合并症]

二、诊断依据（6分）
1. 病史：[年龄/性别/主诉/诱因等支持诊断的信息]
2. 体征：[阳性体征]
3. 辅助检查：[支持诊断的实验室/影像学结果]

三、鉴别诊断（5分）
1. [鉴别诊断1]：[相同点]，但[不同点/不支持点]
2. [鉴别诊断2]：[相同点]，但[不同点/不支持点]
3. [鉴别诊断3]：[相同点]，但[不同点/不支持点]

四、进一步检查（3分）
1. [确诊所需的检查]
2. [排除鉴别诊断的检查]
3. [评估病情严重程度的检查]

五、治疗原则（3分）
1. 一般治疗：[休息/饮食/监护等]
2. 药物治疗：[具体药物类别及目的]
3. 手术/介入治疗：[如适用]
4. 对症/支持治疗
```

## 3. 第二站：体格检查+基本操作（30分）

### 3.1 考试形式
- 操作+口述
- 考试时长：约24分钟
- 两名考官现场评分

### 3.2 体格检查（15分）

**必考系统检查**：

| 系统 | 核心项目 | 常见考点 |
|------|----------|----------|
| 一般检查 | 生命体征、淋巴结 | 血压测量规范、浅表淋巴结触诊顺序 |
| 头颈部 | 甲状腺、巩膜 | 甲状腺触诊手法（双手/单手） |
| 胸部（肺） | 叩诊、听诊 | 叩诊手法、听诊顺序、呼吸音描述 |
| 胸部（心） | 心界叩诊、心音听诊 | 叩诊顺序、五个听诊区、心音分裂 |
| 腹部 | 触诊、叩诊、听诊 | 肝脾触诊手法、移动性浊音、压痛/反跳痛 |
| 神经系统 | 生理/病理反射 | 巴宾斯基征、脑膜刺激征、膝反射 |

**评分要点**：
- 操作规范（手法正确）
- 顺序正确（从头到脚、先视后触再叩听）
- 口述清晰（边做边说）
- 爱伤观念（检查前搓手、告知患者、注意隐私）

### 3.3 基本操作（15分）

**高频操作项目**：

| 操作 | 分值 | 关键步骤 |
|------|------|----------|
| 外科手消毒 | 必考 | 范围（肘上10cm）、时间（3-5分钟）、顺序 |
| 穿脱手术衣/手套 | 高频 | 无菌原则、闭合式戴手套法 |
| 手术区消毒铺巾 | 高频 | 消毒范围（切口15cm）、顺序（中心向外）、铺巾顺序 |
| 缝合与打结 | 高频 | 单纯缝合、打结手法、剪线 |
| 清创术 | 高频 | 冲洗、清创、缝合步骤 |
| 胸腔穿刺 | 高频 | 穿刺点定位、麻醉、进针、抽液量 |
| 腹腔穿刺 | 高频 | 穿刺点定位、体位、抽液量 |
| 腰椎穿刺 | 高频 | 穿刺点（L3-4）、体位、测压 |
| 骨髓穿刺 | 中频 | 穿刺点（髂后上棘）、操作步骤 |
| 导尿术 | 高频 | 消毒顺序、插入深度（男/女不同） |
| CPR | 必考 | 按压位置、深度（5-6cm）、频率（100-120次/分） |
| 气管插管 | 中频 | 体位、喉镜使用、插入深度 |
| 简易呼吸器 | 中频 | 面罩固定、挤压频率 |
| 三腔二囊管 | 中频 | 插入深度、充气量、牵引重量 |
| 电除颤 | 中频 | 能量选择、电极位置、放电安全 |

**操作评分通用要点**：
- 操作前准备（物品、患者体位、知情同意）
- 无菌观念（全程遵守无菌原则）
- 操作规范（手法、顺序、力度）
- 操作后处理（标本送检、观察、记录）
- 人文关怀（解释操作、注意保暖、保护隐私）

## 4. 第三站：多媒体机考（30分）

### 4.1 考试形式
- 计算机化考试
- 考试时长：约15分钟
- 全部选择题

### 4.2 考试内容

| 项目 | 分值 | 题量 | 考查内容 |
|------|------|------|----------|
| 心肺听诊 | 8分 | 4题 | 心音、杂音、呼吸音、附加音 |
| 影像诊断 | 6分 | 3题 | X线、CT |
| 心电图 | 7分 | 3题 | 常见异常心电图判读 |
| 医德医风 | 9分 | 3题 | 医学伦理情景判断 |

### 4.3 心肺听诊高频考点

**心脏听诊**：
| 听诊音 | 特征 | 常见疾病 |
|--------|------|----------|
| 收缩期杂音（二尖瓣区） | 吹风样 | 二尖瓣关闭不全 |
| 舒张期杂音（二尖瓣区） | 隆隆样 | 二尖瓣狭窄 |
| 收缩期杂音（主动脉瓣区） | 喷射样 | 主动脉瓣狭窄 |
| 舒张期杂音（主动脉瓣区） | 叹气样 | 主动脉瓣关闭不全 |
| S3 | 舒张早期 | 心力衰竭 |
| 心包摩擦音 | 与心跳一致 | 心包炎 |

**肺部听诊**：
| 听诊音 | 特征 | 常见疾病 |
|--------|------|----------|
| 湿啰音 | 水泡音 | 肺炎、肺水肿 |
| 干啰音 | 哮鸣音 | 哮喘、COPD |
| 呼吸音减弱 | 伴叩诊浊音 | 胸腔积液 |
| 呼吸音消失 | 伴叩诊鼓音 | 气胸 |
| 胸膜摩擦音 | 与呼吸一致 | 胸膜炎 |

### 4.4 心电图高频考点

| 心电图表现 | 诊断要点 |
|------------|----------|
| 窦性心动过速 | HR>100次/分，P波规律 |
| 窦性心动过缓 | HR<60次/分 |
| 房性早搏 | 提前出现的P'波 |
| 室性早搏 | 提前出现的宽大QRS波 |
| 房颤 | 无P波，f波，RR不规则 |
| 阵发性室上速 | HR150-250次/分，QRS窄 |
| 室速 | 3个以上宽大QRS波连发 |
| 室颤 | 波形杂乱不规则 |
| 一度AVB | PR间期>0.20s |
| 二度I型AVB | PR逐渐延长至脱落 |
| 二度II型AVB | PR恒定，QRS突然脱落 |
| 三度AVB | P与QRS无关 |
| 急性心梗 | ST段抬高/病理性Q波/T波倒置 |

### 4.5 影像诊断高频考点

| 征象 | 诊断 |
|------|------|
| 肺野大片密度增高影 | 大叶性肺炎 |
| 肺野多发斑片影 | 小叶性肺炎 |
| 肺内球形病灶 | 肺癌/结核球 |
| 肋膈角变钝 | 胸腔积液 |
| 肺野透亮无肺纹理 | 气胸 |
| 纵隔向健侧移位 | 大量胸腔积液/张力性气胸 |
| 纵隔向患侧移位 | 肺不张/胸膜肥厚 |
| 心影呈靴形 | 主动脉瓣关闭不全/高血压 |
| 心影呈梨形 | 二尖瓣狭窄 |
| 心影呈烧瓶形 | 心包积液 |
| 膈下游离气体 | 消化道穿孔 |
| 肠管扩张液平 | 肠梗阻 |
| 骨折线 | 骨折 |

### 4.6 医德医风

**考查方向**：
- 知情同意权
- 患者隐私保护
- 医疗保密义务
- 临终关怀伦理
- 医患沟通技巧
- 医疗纠纷处理
- 临床科研伦理
- 传染病报告义务

**解题原则**：
- 以患者利益为优先
- 尊重患者自主权
- 遵守法律法规
- 坚持诚信原则
- 保护患者隐私
- 不得过度医疗

## 5. 技能考试常见失分点

| 站次 | 常见失分 | 预防方法 |
|------|----------|----------|
| 第一站 | 病史采集遗漏阴性鉴别症状 | 按系统逐一询问，模板化书写 |
| 第一站 | 病例分析诊断不完整 | 诊断要写全：主诊断+并发症+功能分级 |
| 第二站 | 操作违反无菌原则 | 每一步操作前检查无菌条件 |
| 第二站 | 缺乏爱伤观念 | 检查前搓手、告知患者、注意保暖 |
| 第三站 | 心电图诊断混淆 | 牢记特征性改变，排除法判读 |
| 通用 | 时间不够 | 提前模拟练习，控制答题节奏 |
