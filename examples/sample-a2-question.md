# A2型题示例 — 心血管系统

## 示例1（中等难度）

男，55岁，突发胸骨后压榨样疼痛4小时，伴大汗、恶心。含服硝酸甘油2次未缓解。
查体：血压80/50mmHg，心率108次/分，律齐，心音低钝，双肺底湿啰音。
心电图示II、III、aVF导联ST段弓背向上抬高0.3-0.4mV，伴T波倒置。
心肌肌钙蛋白I为3.5ng/mL（参考值<0.04）。

最可能的诊断是
A. 急性前壁心肌梗死
B. 急性下壁心肌梗死
C. 不稳定型心绞痛
D. 急性心包炎
E. 主动脉夹层

**答案：B**

**解析**：
- 胸骨后压榨样疼痛>30分钟 + 硝酸甘油不缓解 → 急性心肌梗死
- II、III、aVF导联ST段抬高 → 下壁导联 → 下壁心梗
- cTnI显著升高（3.5ng/mL）→ 心肌坏死确认
- 低血压+肺啰音 → 合并心源性休克/心衰

**诊断公式**：胸痛>30min + 硝酸甘油无效 + ST段抬高 + cTnI升高 = 急性心梗

**考点**：心血管系统-急性心肌梗死的定位诊断
- 前壁：V1-V4
- 广泛前壁：V1-V5（甚至V6、I、aVL）
- 下壁：II、III、aVF
- 侧壁：I、aVL、V5-V6
- 后壁：V7-V9（V1-V2镜像改变）

**易错点**：
- 误选A：前壁心梗应为V1-V4 ST段抬高，本题II、III、aVF抬高为下壁
- 误选C：心绞痛cTnI正常，且硝酸甘油可缓解
- 误选E：主动脉夹层为撕裂样疼痛，向背部放射，心电图无ST段抬高

## 示例2（困难）

女，72岁，反复晕厥3次。查体：血压130/70mmHg，心率42次/分，律齐。
心电图示P波与QRS波群无关，P波频率75次/分，QRS波群频率42次/分，QRS波群宽大畸形。

最可能的诊断是
A. 窦性心动过缓
B. 二度I型房室传导阻滞
C. 二度II型房室传导阻滞
D. 三度房室传导阻滞
E. 病态窦房结综合征

**答案：D**

**解析**：
- P波与QRS波群完全无关（房室分离）→ 三度房室传导阻滞
- P波频率(75) > QRS频率(42) → 心房率快于心室率
- QRS宽大畸形 → 逸搏点在希氏束以下（室性逸搏）
- 反复晕厥 → 脑供血不足（Adams-Stokes综合征）

**诊断公式**：P波与QRS无关 + P频率>QRS频率 = 三度房室传导阻滞

**考点**：心血管系统-房室传导阻滞的鉴别
| 类型 | 心电图特征 | 治疗 |
|------|------------|------|
| 一度AVB | PR间期>0.20s | 无需治疗 |
| 二度I型 | PR逐渐延长至QRS脱落 | 观察/起搏器(有症状) |
| 二度II型 | PR恒定，QRS突然脱落 | 起搏器 |
| 三度AVB | P与QRS完全无关 | 起搏器（永久） |

**易错点**：
- 误选A：窦性心动过缓有P波且PR间期固定，P:QRS=1:1
- 误选B/C：二度AVB仍有部分P波下传，非完全分离

## 示例3（简单）

男，60岁，高血压病史15年，长期口服氨氯地平5mg/d，血压控制在145/90mmHg左右。
近1月感乏力、双下肢水肿。查体：血压150/95mmHg，心率78次/分，
双下肢凹陷性水肿。实验室检查：血钾3.0mmol/L，血肌酐正常。

该患者水肿最可能的原因是
A. 心力衰竭
B. 肾功能不全
C. 低蛋白血症
D. 药物不良反应
E. 深静脉血栓

**答案：D**

**解析**：
- 服用氨氯地平（钙通道阻滞剂）→ 常见副作用为下肢水肿
- 低钾血症(3.0mmol/L) → 也可能与利尿剂或其他药物有关
- 血肌酐正常 → 排除肾功能不全
- 无心衰表现 → 排除心源性水肿

**考点**：药理学-降压药物副作用
| 药物类别 | 代表药 | 常见副作用 |
|----------|--------|------------|
| CCB | 氨氯地平 | 下肢水肿、头痛、面色潮红 |
| ACEI | 依那普利 | 干咳、高钾、肾功能恶化 |
| ARB | 缬沙坦 | 高钾（较ACEI干咳少） |
| β受体阻滞剂 | 美托洛尔 | 心动过缓、支气管痉挛 |
| 利尿剂 | 氢氯噻嗪 | 低钾、高尿酸、高血糖 |
| α受体阻滞剂 | 特拉唑嗪 | 体位性低血压 |

**易错点**：误选A（无心衰证据如呼吸困难、肺啰音、颈静脉怒张）
