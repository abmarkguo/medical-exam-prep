# A3/A4型题示例 — 消化系统

## A4型渐进式病例

### 初始场景

男，52岁，饮酒后突发上腹部剧痛6小时，伴恶心呕吐，呕吐物为胃内容物。
既往有胆囊结石病史3年。查体：T 38.2°C，P 120次/分，R 24次/分，
BP 100/65mmHg。痛苦面容，屈曲体位。腹平坦，上腹部明显压痛、反跳痛，
腹肌紧张，肠鸣音减弱。无皮肤巩膜黄染。

---

### 问题1：最可能的诊断是

A. 急性胃肠炎
B. 急性胆囊炎
C. 急性胰腺炎
D. 消化性溃疡穿孔
E. 急性心肌梗死

**答案：C**

**解析**：
- 饮酒（诱因）+ 胆囊结石病史（胆源性胰腺炎高危）
- 突发上腹剧痛 + 屈曲体位（胰腺炎典型体位）
- 发热 + 心率快 + 呼吸快（全身炎症反应）
- 上腹压痛反跳痛 + 肠鸣音减弱（腹膜炎体征）
- 无膈下游离气体（排除穿孔，但需影像学确认）

**诊断公式**：饮酒/胆石病史 + 上腹剧痛 + 腹膜刺激征 = 急性胰腺炎

---

### 追加信息1

实验室检查：血WBC 16.8×10^9/L，N 89%，血淀粉酶680U/L（正常<120），
脂肪酶520U/L（正常<60）。肝功能：ALT 85U/L，AST 72U/L，
TBIL 35μmol/L，DBIL 22μmol/L。血糖9.8mmol/L，血钙1.85mmol/L。
腹部CT示胰腺肿胀，周围渗出，未见坏死。

### 问题2：该患者的Ranson评分中，入院时已有几项达标

A. 1项
B. 2项
C. 3项
D. 4项
E. 5项

**答案：C**

**解析**：
Ranson评分（入院时5项）：
| 指标 | 标准 | 患者 | 达标 |
|------|------|------|------|
| 年龄 | >55岁 | 52岁 | 否 |
| WBC | >16×10^9/L | 16.8 | 是 |
| 血糖 | >11.1mmol/L | 9.8 | 否 |
| AST | >250U/L | 72 | 否 |
| LDH | >350U/L | 未测 | - |

Ranson评分（入院48小时6项）：
| 指标 | 标准 | 患者 | 达标 |
|------|------|------|------|
| HCT下降 | >10% | 待观察 | - |
| BUN升高 | >1.8mmol/L | 待观察 | - |
| 血钙 | <2.0mmol/L | 1.85 | 是 |
| PaO2 | <60mmHg | 未测 | - |
| 碱缺失 | >4mmol/L | 未测 | - |
| 体液丢失 | >6L | 待计算 | - |

已知达标：WBC↑ + 血钙↓ + （入院后还需评估）
入院时已确定达标：WBC + 血钙 = 2项（入院时指标中仅WBC达标，血钙属于48h指标）

修正：入院时达标项为WBC（>16），其余入院时指标（年龄<55，血糖<11.1，AST<250）均未达标。但血钙属于48小时指标。

**注意**：本题需仔细区分入院时和48小时指标。入院时达标仅1项（WBC），但如果题目问"目前已知几项达标"则为2项（WBC + 血钙）。

**答案修正为B**（入院时Ranson标准中WBC>16为1项，加上血钙<2.0属48h标准为1项，共2项已知阳性）

---

### 追加信息2

入院24小时后，患者出现呼吸困难，SpO2降至88%（面罩吸氧5L/min），
血压降至85/50mmHg，尿量减少至20ml/h。复查CT示胰腺坏死面积约30%，
双侧胸腔积液。

### 问题3：当前最可能的并发症是

A. 急性呼吸窘迫综合征(ARDS)
B. 急性心力衰竭
C. 肺部感染
D. 肺栓塞
D. 气胸

**答案：A**

**解析**：
- 重症急性胰腺炎 + 双侧胸腔积液 → ARDS高危
- 面罩吸氧5L/min下SpO2仅88% → 低氧血症
- 全身炎症反应→ 肺毛细血管渗漏→ ARDS
- ARDS是重症胰腺炎的严重并发症，死亡率高

**ARDS诊断标准**：
1. 有高危因素（重症胰腺炎）
2. 急性起病
3. PaO2/FiO2≤300（面罩5L/min约FiO2=40%，PaO2约55mmHg→比值137）
4. 双肺浸润影
5. 排除心源性肺水肿

---

### 追加信息3

患者转入ICU，予机械通气、补液、抑酸抑酶、抗感染等治疗。
第3天出现精神症状，随后出现上消化道出血，血PT延长，
PLT降至45×10^9/L，D-二聚体明显升高，纤维蛋白原降至1.2g/L。

### 问题4：该患者目前合并

A. 肝性脑病
B. 消化道溃疡出血
C. 弥散性血管内凝血(DIC)
D. 维生素K缺乏
E. 特发性血小板减少性紫癜

**答案：C**

**解析**：
重症胰腺炎→全身炎症反应→DIC

DIC诊断依据：
- PLT<50×10^9/L（本例45×10^9/L）
- PT延长
- D-二聚体明显升高
- 纤维蛋白原<1.5g/L（本例1.2g/L）
- 多发出血（消化道出血）

**DIC治疗原则**：
1. 治疗原发病（控制胰腺炎）
2. 抗凝：肝素/低分子肝素
3. 补充凝血因子：新鲜冰冻血浆、冷沉淀
4. 抗纤溶：氨甲环酸（继发纤溶亢进时）
5. 血小板输注（出血严重时）

---

### 问题5：该患者的综合治疗方案中最核心的是

A. 立即手术清除坏死组织
B. 内科综合治疗为主，必要时介入/手术
C. 大剂量糖皮质激素
D. 血液透析
E. 内镜逆行胰胆管造影(ERCP)

**答案：B**

**解析**：
重症急性胰腺炎治疗原则：
1. **内科综合治疗（核心）**：
   - 禁食胃肠减压
   - 液体复苏（目标导向补液）
   - 抑酸抑酶（PPI + 生长抑素/奥曲肽）
   - 镇痛（哌替啶，禁用吗啡——致Oddi括约肌痉挛）
   - 抗感染（碳青霉烯类或喹诺酮+甲硝唑）
   - 营养支持（早期肠内营养）
   - 器官功能支持（呼吸机/CRRT）

2. **介入/手术（必要时）**：
   - 感染性坏死→引流/清创（延迟手术，4周后）
   - 胆道梗阻→ERCP（胆源性胰腺炎伴胆管炎/梗阻）

3. **不推荐**：
   - 早期手术（增加死亡率）
   - 大剂量激素（无益）
   - 常规预防性抗生素（不推荐）

**考点总结**：
- 急性胰腺炎的病因（胆源性最常见→我国）
- 诊断标准（淀粉酶/脂肪酶3倍升高+影像学）
- 严重程度评估（Ranson/APACHE-II/BISAP）
- 重症并发症（ARDS/DIC/感染/胰性脑病）
- 治疗原则（内科为主，手术为辅）
- 禁忌药物（吗啡——致Oddi括约肌痉挛）
