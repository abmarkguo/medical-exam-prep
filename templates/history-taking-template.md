# 病史采集模板 (History Taking Template)

> 模拟实践技能考试第一站病史采集（15分）

## 1. 考试要求

- 给定主诉，书写完整病史
- 时间约10分钟
- 总分15分
- 需包含：一般项目、主诉、现病史、既往史、个人史、婚育史、家族史

## 2. 标准模板

```
一、一般项目（0.5分）
姓名：XXX    性别：X    年龄：XX岁
民族：X族    婚姻：已婚/未婚    职业：XXX
籍贯：XXX    入院日期：XXXX年XX月XX日
记录日期：XXXX年XX月XX日

二、主诉（1分）
[主要症状] [持续时间]
（要求：简明扼要，不超过20字，用医学术语）
（示例：转移性右下腹痛6小时 / 反复上腹痛3年，加重伴黑便2天）

三、现病史（7分）— 核心得分部分

1. 起病情况与患病时间（1分）
   患者于[时间]前，[诱因/无明确诱因]下出现[症状]，起病[急/缓]

2. 主要症状特点（2分）
   - 部位：[具体部位/放射部位]
   - 性质：[钝痛/绞痛/刀割样/烧灼样/胀痛等]
   - 程度：[轻/中/重/能否忍受]
   - 持续时间：[持续性/阵发性/间歇性，每次持续多久]
   - 诱因：[进食/体位/活动/情绪等]
   - 加重/缓解因素：[什么情况下加重/缓解]

3. 病情发展与演变（1分）
   [症状是逐渐加重/减轻/时好时坏，有无新症状出现]

4. 伴随症状（1分）
   [有无发热/恶心呕吐/腹泻/呼吸困难/头晕等]
   [有鉴别意义的阴性症状：如无畏寒发热、无黄疸、无血尿等]

5. 诊疗经过（1分）
   [发病后是否就医，做过什么检查，诊断为什么，用过什么药，效果如何]

6. 一般情况（1分）
   发病以来，精神[好/差]，睡眠[正常/差]，
   食欲[正常/减退]，大便[X次/天，性状]，小便[X次/天，性状]，
   体重[无明显变化/减轻Xkg]

四、既往史（2分）
1. 既往疾病史：[高血压/糖尿病/冠心病/肝炎/结核等，患病年限及治疗情况]
2. 传染病史：[肝炎/结核/伤寒等]
3. 手术外伤史：[何时做过何种手术/外伤]
4. 输血史：[有/无，血型]
5. 过敏史：[药物/食物过敏，具体表现] / 否认药物及食物过敏史
6. 预防接种史：[按计划接种/不详]

五、个人史（1分）
1. 出生地及居住地：[出生地，是否到过疫区]
2. 职业史：[职业，有无特殊暴露史]
3. 生活习惯：[吸烟X年X支/天，饮酒X年X两/天]
4. 冶游史：[否认/有]

六、婚育史（1分）
1. 婚姻史：[结婚年龄，配偶健康状况]
2. 生育史：[足月产X胎，早产X胎，流产X胎，存活X子女]
3. 月经史（女性必问）：
   初潮年龄XX岁，月经周期XX天，经期XX天，末次月经XXXX年XX月XX日
   （绝经者：绝经年龄XX岁）

七、家族史（1分）
1. 父母：[健康/患何种疾病/已故，死因]
2. 兄弟姐妹：[健康/患何种疾病]
3. 子女：[健康/患何种疾病]
4. 家族中类似疾病史：[有/无]
5. 家族遗传性疾病史：[有/无]
（如无特殊：否认家族遗传性疾病及类似疾病史）

八、问诊技巧（1.5分）
- 条理性强，按规范顺序询问
- 逻辑清晰，前后连贯
- 使用医学术语
- 关心患者，态度和蔼
```

## 3. 常见主诉及问诊要点

### 3.1 腹痛
```
起病：何时开始，急/缓，有无诱因（饮食/外伤/运动）
特点：部位（具体+转移/放射）、性质（绞痛/钝痛/刀割样）、
      程度、持续时间、阵发/持续
加重/缓解：进食/体位/排便/排气后变化
伴随：发热/恶心呕吐/腹泻/便秘/黄疸/血尿/阴道出血
      阴性症状：无畏寒发热、无黄疸、无血尿等
一般情况：精神/睡眠/食欲/大小便/体重
```

### 3.2 胸痛
```
起病：何时开始，有无诱因（活动/情绪/外伤）
特点：部位、性质（压榨样/撕裂样/针刺样）、范围、放射部位、
      持续时间、发作频率
加重/缓解：活动/休息/体位/硝酸甘油
伴随：出汗/呼吸困难/恶心呕吐/晕厥/咯血/发热
      阴性症状：无呼吸困难、无晕厥等
```

### 3.3 发热
```
起病：何时开始，有无诱因（受凉/接触史/旅行史）
特点：最高体温、热型（稽留热/弛张热/间歇热/不规则热）、
      持续时间、升降方式（骤升/缓升）
加重/缓解：退热药效果/自汗/盗汗
伴随：寒战/头痛/咳嗽咳痰/腹痛腹泻/尿频尿急/皮疹/关节痛
      淋巴结肿大/出血倾向
流行病学：疫区居住/接触史/蚊虫叮咬/不洁饮食
```

### 3.4 呼吸困难
```
起病：何时开始，急/缓，有无诱因
特点：活动后/休息时、端坐呼吸/夜间阵发性、发作频率、持续时间
加重/缓解：体位/活动/用药
伴随：咳嗽咳痰/咯血/胸痛/发热/水肿/心悸/晕厥
既往：哮喘/COPD/心脏病/肺栓塞高危
```

### 3.5 水肿
```
起病：何时开始，从何部位开始（眼睑/下肢/全身）
特点：凹陷性/非凹陷性、晨起/晚间明显、对称/不对称
加重/缓解：体位变化/活动/休息
伴随：尿量变化/尿色异常/泡沫尿/胸闷/腹胀/黄疸
既往：肾脏病/心脏病/肝病/甲状腺疾病
```

## 4. 评分自检清单

| 项目 | 检查内容 | 自评 |
|------|----------|------|
| 一般项目 | 是否填写完整 | |
| 主诉 | 是否简明（<20字），是否含症状+时间 | |
| 现病史-起病 | 有无起病时间、诱因、急缓 | |
| 现病史-特点 | 部位/性质/程度/时间/诱因/加重缓解是否齐全 | |
| 现病史-演变 | 有无病情变化描述 | |
| 现病史-伴随 | 有无伴随症状+阴性鉴别症状 | |
| 现病史-诊疗 | 有无就医/用药/效果 | |
| 现病史-一般 | 精神/睡眠/食欲/大小便/体重是否齐全 | |
| 既往史 | 疾病史/手术史/过敏史是否齐全 | |
| 个人史 | 出生地/职业/烟酒/冶游 | |
| 婚育史 | 婚姻/生育/月经（女性） | |
| 家族史 | 父母/兄弟姐妹/遗传病 | |
| 问诊技巧 | 条理/逻辑/术语/态度 | |
