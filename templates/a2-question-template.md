# A2型题生成模板 (A2 Question Template)

## 模板结构

```
[患者性别/年龄]，[主诉/症状描述]，[体征/检查结果]。[问题]

A. [选项A]
B. [选项B]
C. [选项C]
D. [选项D]
E. [选项E]

答案：[正确选项]
解析：[诊断思路+选项分析]
考点：[对应知识点]
诊断公式：[一句话诊断公式]
易错点：[常见错误分析]
```

## 生成规范

### 1. 题干设计要素
- **人口学信息**：年龄、性别（重要诊断线索）
- **主诉**：主要症状+持续时间
- **现病史要点**：症状特点、诱因、加重/缓解因素
- **体征**：阳性体征（阴性体征酌情加入以助鉴别）
- **辅助检查**：关键阳性结果
- **问题**：最可能诊断/首选检查/首选治疗

### 2. 难度控制
- 简单：1-2个诊断线索，直接对应
- 中等：3-4个诊断线索，需简单鉴别
- 困难：含干扰信息，需排除鉴别诊断

### 3. 干扰项设计原则
- 症状部分相似的疾病
- 同一系统的其他疾病
- 易混淆的诊断
- 不可过度刁难

## 生成示例

### 示例1：心血管系统
```
男，62岁，突发胸骨后压榨样疼痛2小时，向左肩背放射，伴大汗、恶心。
含服硝酸甘油未缓解。查体：血压90/60mmHg，心率95次/分，律齐，
心音低钝。心电图示V1-V4导联ST段弓背向上抬高0.3mV。

最可能的诊断是
A. 不稳定型心绞痛
B. 急性前壁心肌梗死
C. 急性心包炎
D. 主动脉夹层
E. 肺栓塞

答案：B
解析：老年男性+突发胸骨后压榨样疼痛+硝酸甘油不缓解+心电图V1-V4 ST段抬高
=急性前壁心肌梗死。心绞痛含服硝酸甘油可缓解，且无ST段持续抬高；
心包炎胸痛与体位有关，ST段呈弓背向下抬高；主动脉夹层为撕裂样疼痛
向背部放射，双侧血压不等；肺栓塞以呼吸困难为主。
考点：心血管系统-急性心肌梗死
诊断公式：老年+胸痛>30min+硝酸甘油无效+ST段抬高=急性心梗
易错点：误选A（不稳定型心绞痛硝酸甘油可缓解，且无ST段持续抬高）
```

### 示例2：呼吸系统
```
女，65岁，反复咳嗽咳痰20年，加重伴气促1周。吸烟史40年，每日20支。
查体：桶状胸，双肺呼吸音低，呼气延长，可闻及干啰音。
肺功能示FEV1/FVC=65%，FEV1占预计值55%。

最可能的诊断是
A. 支气管哮喘
B. 慢性阻塞性肺疾病
C. 支气管扩张
D. 肺结核
E. 肺癌

答案：B
解析：长期吸烟史+慢性咳嗽咳痰+桶状胸+呼气延长+FEV1/FVC<70%
=慢性阻塞性肺疾病(COPD)，GOLD 2级。哮喘以发作性喘息为特点，
支气管舒张试验阳性，肺功能可逆；支扩以大量脓痰和反复咯血为特点；
肺结核有结核中毒症状；肺癌多为老年人，可有体重下降。
考点：呼吸系统-COPD
诊断公式：吸烟史+咳痰喘+FEV1/FVC<70%=COPD
易错点：误选A（哮喘为可逆性气流受限，COPD为不可逆）
```

### 示例3：消化系统
```
男，45岁，上腹痛3年，多在餐后1小时出现，持续1-2小时可自行缓解。
近1周腹痛加重，伴黑便2次。胃镜示胃角溃疡，直径1.5cm，Hp阳性。

首选的治疗方案是
A. 质子泵抑制剂+铋剂+阿莫西林+克拉霉素，疗程14天
B. 质子泵抑制剂，疗程4周
C. 胃黏膜保护剂，疗程8周
D. 立即手术治疗
E. 中医中药治疗

答案：A
解析：胃溃疡+Hp阳性=需根除Hp。标准四联疗法为PPI+铋剂+两种抗生素
（阿莫西林+克拉霉素），疗程14天，根除后再继续PPI治疗4-6周
直至溃疡愈合。单纯抑酸不能解决Hp感染；手术指征为穿孔、大出血
内科无效、癌变等。
考点：消化系统-消化性溃疡
诊断公式：餐后痛+胃镜见溃疡+Hp阳性=胃溃疡合并Hp感染
易错点：误选B（单纯PPI不能根除Hp，溃疡易复发）
```
