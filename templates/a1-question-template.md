# A1型题生成模板 (A1 Question Template)

## 模板结构

```
[单句陈述题干]
A. [选项A]
B. [选项B]
C. [选项C]
D. [选项D]
E. [选项E]

答案：[正确选项]
解析：[详细解释]
考点：[对应知识点]
易错点：[常见错误分析]
```

## 生成规范

### 1. 题干要求
- 单句陈述，简洁明确
- 考查纯知识点，不含临床场景
- 使用"最""主要""首选""除外"等限定词
- 避免模糊表述

### 2. 选项设计
- 五个选项（A-E），唯一最佳答案
- 干扰项需具有迷惑性
- 选项长度相近
- 避免"以上都是/都不是"

### 3. 解析要求
- 说明正确答案的依据
- 解释错误选项为何不对
- 引用权威来源
- 控制在100-200字

## 生成示例

### 示例1：病理学
```
细胞坏死最主要的形态学标志是
A. 线粒体肿胀
B. 核碎裂
C. 胞质嗜酸性增强
D. 胞质脂滴增加
E. 自噬泡增多

答案：B
解析：细胞坏死的形态学改变主要在细胞核，表现为核固缩、核碎裂、核溶解，
其中核碎裂是细胞坏死最主要的形态学标志。线粒体肿胀和胞质改变是继发性改变。
考点：病理学-细胞损伤与坏死
易错点：误选A（线粒体肿胀是早期可逆性损伤，非坏死标志）
```

### 示例2：药理学
```
ACEI最常见的不良反应是
A. 低钾血症
B. 干咳
C. 心动过缓
D. 高尿酸血症
E. 肝功能损害

答案：B
解析：ACEI抑制血管紧张素转换酶，同时抑制缓激肽降解，缓激肽在肺部蓄积
导致干咳，发生率约10-20%，是ACEI最常见的不良反应，也是停药的主要原因。
考点：药理学-肾素-血管紧张素系统药物
易错点：误选A（ACEI反而可能引起高钾血症，因其抑制醛固酮分泌）
```

### 示例3：生理学
```
正常成年人安静状态下，心率的正常范围是
A. 40-60次/分
B. 60-100次/分
C. 80-120次/分
D. 100-150次/分
E. 60-80次/分

答案：B
解析：正常成年人安静状态下的心率范围为60-100次/分。
低于60次/分为心动过缓，高于100次/分为心动过速。
考点：生理学-心血管生理
易错点：误选E（60-80是理想范围，但正常范围上限为100）
```

## 批量生成格式

当用户要求批量生成A1型题时，按以下格式输出：

```
### A1型题练习（共N题）

**第1题**
[题干]
A. ...
B. ...
C. ...
D. ...
E. ...
答案：X
解析：...
考点：...

**第2题**
...

---

### 答题情况统计
- 总题数：N
- 建议用时：N × 30秒
- 涉及考点：[列出]
```
