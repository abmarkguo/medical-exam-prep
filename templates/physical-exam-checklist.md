# 体格检查清单 (Physical Exam Checklist)

> 模拟实践技能考试第二站体格检查（15分）

## 1. 通用原则

### 1.1 检查前准备
- [ ] 洗手、搓手（体现爱伤观念）
- [ ] 自我介绍、核对患者身份
- [ ] 解释检查目的、取得配合
- [ ] 保护患者隐私（拉帘/关门）
- [ ] 检查者站位（通常在患者右侧）
- [ ] 患者体位适当（仰卧/坐位/侧卧）

### 1.2 检查顺序
- 总原则：从头到脚，先视后触再叩听
- 左右对比，先健侧后患侧
- 先一般后专科

### 1.3 评分要点
- 手法正确规范
- 顺序正确
- 口述清晰（边做边说）
- 爱伤观念（搓手、告知、保暖）
- 结果描述准确

## 2. 一般检查

### 2.1 生命体征
| 项目 | 操作要点 | 正常值 |
|------|----------|--------|
| 体温 | 腋测法，5-10分钟 | 36-37°C |
| 脉搏 | 触诊桡动脉30秒×2 | 60-100次/分 |
| 呼吸 | 观察胸廓起伏1分钟 | 12-20次/分 |
| 血压 | 坐位/卧位，右上臂，听诊法 | <140/90mmHg |

### 2.2 血压测量规范
- [ ] 患者安静休息5分钟
- [ ] 坐位/卧位，上臂与心脏同高
- [ ] 袖带下缘距肘窝2-3cm
- [ ] 袖带松紧度适中（可插入1-2指）
- [ ] 听诊器胸件放于肱动脉搏动处（不塞入袖带内）
- [ ] 充气至搏动消失后加压20-30mmHg
- [ ] 缓慢放气（2-3mmHg/秒）
- [ ] 记录收缩压（柯氏音第一时相）和舒张压（柯氏音第五时相）

### 2.3 浅表淋巴结触诊
顺序：耳前→耳后→乳突区→枕骨下区→颌下→颏下→颈前三角→颈后三角→锁骨上窝→腋窝→滑车上→腹股沟→腘窝

## 3. 头颈部检查

### 3.1 甲状腺触诊（双手法）
- [ ] 站在患者背后
- [ ] 双手拇指置于颈后，其余四指绕至颈前
- [ ] 嘱患者做吞咽动作
- [ ] 触诊甲状腺峡部及两侧叶
- [ ] 注意：大小、质地、有无结节、有无压痛、有无震颤
- [ ] 描述：甲状腺是否肿大、有无结节、质地如何

### 3.2 气管位置检查
- [ ] 患者仰卧，颈部自然伸直
- [ ] 检查者食指和无名指分别置于两侧胸锁关节上
- [ ] 中指置于气管正中
- [ ] 观察中指与两侧手指的距离是否相等
- [ ] 描述：气管居中/偏移（向何侧）

## 4. 胸部检查（肺部）

### 4.1 视诊
- [ ] 胸廓形态（正常/桶状胸/扁平胸/佝偻病胸）
- [ ] 呼吸运动（对称/不对称，频率、节律、深度）
- [ ] 肋间隙（正常/增宽/变窄）

### 4.2 触诊
- [ ] 胸廓扩张度：双手置于胸廓两侧下部，嘱患者深呼吸，观察两手活动度
- [ ] 语音震颤：双手尺侧缘置于两侧胸壁，嘱患者发"1"音，自上而下对比
- [ ] 胸膜摩擦感：双手置于胸廓下侧部，感受摩擦感

### 4.3 叩诊
- [ ] 顺序：自上而下，由前向后，左右对比
- [ ] 先叩前胸，再叩侧胸，最后叩背部
- [ ] 叩诊音：清音（正常）/浊音/实音/过清音/鼓音
- [ ] 肺界叩诊：肺上界（Kronig峡）、肺下界、肺下界移动度

### 4.4 听诊
- [ ] 顺序：自上而下，由前向后，左右对比
- [ ] 每个部位至少听1-2个呼吸周期
- [ ] 听诊内容：呼吸音（正常/减弱/消失）、啰音（干/湿）、语音共振、胸膜摩擦音

## 5. 胸部检查（心脏）

### 5.1 视诊
- [ ] 心前区隆起（正常/异常）
- [ ] 心尖搏动位置（正常：左侧第5肋间锁骨中线内侧0.5-1cm）
- [ ] 心尖搏动范围（正常直径2-2.5cm）
- [ ] 异常搏动

### 5.2 触诊
- [ ] 心尖搏动：右手全掌→指腹确认
- [ ] 震颤：用手掌尺侧感受
- [ ] 心包摩擦感：胸骨左缘第4肋间

### 5.3 叩诊
- [ ] 方法：指指叩诊法，由外向内，由下向上
- [ ] 顺序：先叩左界（从心尖搏动外2-3cm开始），再叩右界（从肝浊音界上一肋间开始）
- [ ] 逐肋间叩诊至第2肋间
- [ ] 标记各点，连线测量

### 5.4 听诊（五个听诊区）
| 听诊区 | 位置 | 听诊内容 |
|--------|------|----------|
| 二尖瓣区 | 心尖部（第5肋间左锁骨中线内侧） | S1、二尖瓣杂音 |
| 主动脉瓣区 | 胸骨右缘第2肋间 | S2、主动脉瓣杂音 |
| 主动脉瓣第二听诊区 | 胸骨左缘第3肋间 | 主动脉瓣关闭不全杂音 |
| 肺动脉瓣区 | 胸骨左缘第2肋间 | 肺动脉瓣杂音 |
| 三尖瓣区 | 胸骨左缘第4-5肋间 | 三尖瓣杂音 |

听诊内容：心率、心律、心音（S1/S2有无异常）、额外心音、杂音（部位/时期/性质/强度/传导）、心包摩擦音

## 6. 腹部检查

### 6.1 检查顺序（特殊：视→听→叩→触）

### 6.2 视诊
- [ ] 腹部外形（平坦/膨隆/凹陷）
- [ ] 呼吸运动
- [ ] 腹壁静脉曲张（如有：判断血流方向）
- [ ] 胃肠型及蠕动波
- [ ] 手术瘢痕、疝

### 6.3 听诊
- [ ] 肠鸣音：右下腹，至少1分钟（正常4-5次/分）
- [ ] 血管杂音：腹主动脉区、肾动脉区
- [ ] 振水音：左右摇晃上腹部

### 6.4 叩诊
- [ ] 肝浊音界：正常上界在右锁骨中线第5肋间
- [ ] 肝区叩击痛
- [ ] 移动性浊音：仰卧→侧卧叩诊音变化（查腹水）
- [ ] 肾区叩击痛：肋脊角处叩击

### 6.5 触诊（最重点）
- [ ] 腹壁柔软度（软/紧张）
- [ ] 压痛及反跳痛：先非疼痛区，后疼痛区
- [ ] 肝脏触诊：右手自右下腹向肋缘方向触诊，嘱患者深呼吸
- [ ] 脾脏触诊：左手绕过患者腹前方置于左腰部，右手自脐向左肋缘触诊
- [ ] 胆囊触痛（Murphy征）：拇指置于胆囊点，嘱深吸气，吸气过程中因疼痛突然屏气为阳性
- [ ] 腹部包块

## 7. 神经系统检查

### 7.1 生理反射
| 反射 | 检查方法 | 反应 |
|------|----------|------|
| 角膜反射 | 棉絮轻触角膜 | 闭眼 |
| 肱二头肌反射 | 叩击置于肱二头肌腱上的拇指 | 肘屈曲 |
| 肱三头肌反射 | 叩击鹰嘴上方的肱三头肌腱 | 肘伸直 |
| 膝反射 | 叩击髌骨下方的股四头肌腱 | 膝伸直 |
| 跟腱反射 | 叩击跟腱 | 足跖屈 |

### 7.2 病理反射
| 反射 | 检查方法 | 阳性表现 |
|------|----------|----------|
| 巴宾斯基征 | 沿足底外缘自后向前划至小趾根部 | 拇趾背伸，其余四趾扇形展开 |
| 奥本海姆征 | 沿胫骨前缘自上而下推压 | 同上 |
| 戈登征 | 用力捏压腓肠肌 | 同上 |
| 查多克征 | 在外踝下方沿足背外缘划 | 同上 |
| 霍夫曼征 | 弹拨中指指甲 | 其余手指屈曲 |

### 7.3 脑膜刺激征
| 体征 | 检查方法 | 阳性表现 |
|------|----------|----------|
| 颈强直 | 患者仰卧，被动前屈颈部 | 颈部抵抗，下颌不能贴近胸壁 |
| 克匿格征 | 仰卧，屈髋屈膝90°，再伸膝 | 伸膝受限<135°，伴疼痛 |
| 布鲁津斯基征 | 仰卧，被动前屈颈部 | 双下肢屈曲缩腹 |

## 8. 常见扣分点

| 项目 | 常见扣分 | 预防 |
|------|----------|------|
| 爱伤观念 | 未搓手/未告知/未保暖 | 每次检查前搓手、告知 |
| 顺序错误 | 腹部先触后听 | 腹部特殊：视听叩触 |
| 手法不规范 | 叩诊指位、触诊力度 | 严格按规范练习 |
| 描述不准确 | 混淆杂音分期/性质 | 牢记标准描述 |
| 遗漏项目 | 忘记检查对侧 | 左右对比是原则 |
| 时间不够 | 动作太慢 | 提前练习控制节奏 |
