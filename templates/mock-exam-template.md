## 4. 全真模拟考试

### 4.1 考试环境模拟要求
- [ ] 安静无干扰的环境
- [ ] 计时器（严格120分钟/单元）
- [ ] 不查阅任何资料
- [ ] 模拟机考：跨题型不可回看
- [ ] 一次性完成一个单元

### 4.2 模考流程
```
1. 准备阶段（5分钟）
   - 阅读考试须知
   - 准备计时器
   - 调整心态

2. 答题阶段（120分钟）
   - A1型题：30分钟（快速作答）
   - A2型题：35分钟（重点分析）
   - B1型题：15分钟（先读选项）
   - A3/A4型题：35分钟（综合推理）
   - 检查标记题：5分钟

3. 评分阶段（30分钟）
   - 对照答案评分
   - 记录错题
   - 分析错误原因

4. 复盘阶段（30分钟）
   - 错题归类
   - 知识点回顾
   - 调整复习计划
```

### 4.3 成绩评估标准

| 单元得分 | 评估 | 建议 |
|----------|------|------|
| <75分(<50%) | 不合格 | 系统复习该单元内容 |
| 75-90分(50-60%) | 临界 | 针对性强化薄弱科目 |
| 90-105分(60-70%) | 合格 | 查漏补缺，提高准确性 |
| 105-120分(70-80%) | 良好 | 保持优势，攻克难点 |
| >120分(>80%) | 优秀 | 保持状态，冲刺高分 |

**四单元总分评估**：

| 总分 | 预计结果 | 建议 |
|------|----------|------|
| <300分 | 不通过 | 全面系统复习 |
| 300-360分 | 临界 | 针对性突破薄弱单元 |
| 360-420分 | 通过 | 保持状态，适当提高 |
| >420分 | 稳过 | 保持信心，轻松应对 |
