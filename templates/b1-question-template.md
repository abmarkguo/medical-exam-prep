# B1型题生成模板 (B1 Question Template)

## 模板结构

```
【共用选项】
A. [选项A]
B. [选项B]
C. [选项C]
D. [选项D]
E. [选项E]

【第1题】[题干1]
答案：X

【第2题】[题干2]
答案：X

【第3题】[题干3]
答案：X

解析：
[逐题解析]
```

## 生成规范

### 1. 选项设计
- 五个共用选项（A-E）
- 选项可为：疾病名、药物名、检查方法、病理类型等
- 选项间需有可比性（同一类别）
- 选项可重复选用或不用

### 2. 题干设计
- 2-5道题共用选项
- 每题考查一个知识点
- 题干简洁，指向明确
- 考查鉴别、分类、配伍能力

### 3. 常见出题方向
- **疾病鉴别**：不同疾病的特征性表现
- **药物匹配**：药物与适应症/副作用
- **检查方法**：不同疾病的首选检查
- **病理分型**：不同病理类型的特征
- **分期分级**：疾病不同阶段的处理

## 生成示例

### 示例1：黄疸鉴别
```
【共用选项】
A. 间接胆红素升高为主
B. 直接胆红素升高为主
C. 直接和间接胆红素均升高
D. 胆红素正常
E. 胆红素降低

【第1题】溶血性黄疸的特征是
答案：A
解析：溶血导致大量红细胞破坏，产生过多间接胆红素，超过肝脏处理能力，
以间接胆红素升高为主。

【第2题】梗阻性黄疸的特征是
答案：B
解析：胆道梗阻导致直接胆红素无法排入肠道，反流入血，以直接胆红素升高为主，
伴尿胆原减少/消失，大便呈陶土色。

【第3题】肝细胞性黄疸的特征是
答案：C
解析：肝细胞损伤既影响胆红素摄取转化(间接升高)又影响排泄(直接升高)，
故两者均升高。
```

### 示例2：抗心律失常药物
```
【共用选项】
A. 利多卡因
B. 胺碘酮
C. 腺苷
D. 维拉帕米
E. 阿托品

【第1题】急性心肌梗死并发室性心动过速首选
答案：A
解析：利多卡因是急性心梗并室速的首选药物，静脉注射50-100mg。

【第2题】阵发性室上性心动过速首选
答案：C
解析：腺苷是阵发性室上速的首选药物，静脉快速推注，半衰期极短(10秒)。

【第3题】尖端扭转型室速可选用
答案：B
解析：胺碘酮可用于尖端扭转型室速，但需注意QT间期。
实际上首选硫酸镁，但选项中无。

【第4题】严重窦性心动过缓首选
答案：E
解析：阿托品是窦性心动过缓的首选药物，0.5-1mg静脉注射。
```

### 示例3：肺炎病原体
```
【共用选项】
A. 肺炎链球菌
B. 肺炎支原体
C. 金黄色葡萄球菌
D. 铜绿假单胞菌
E. 白色念珠菌

【第1题】大叶性肺炎最常见的病原体是
答案：A

【第2题】表现为间质性肺炎，冷凝集试验阳性的是
答案：B

【第3题】肺部X线表现为多发性脓肿或空洞的是
答案：C

【第4题】长期使用广谱抗生素后出现的肺炎，病原体多为
答案：E

解析：
- 肺炎链球菌：青壮年，铁锈色痰，大叶性分布
- 肺炎支原体：青少年，干咳为主，间质性肺炎，冷凝集试验阳性
- 金黄色葡萄球菌：脓血痰，多发性空洞/脓肿，病情重
- 铜绿假单胞菌：院内感染，绿色脓痰
- 白色念珠菌：长期用抗生素/免疫低下者
```

```
答案：D
```

## 批量生成格式

```
### B1型题练习（共N组）

**第1组** [主题描述]
共用选项：A-E
题1-3

**第2组**
共用选项：A-E
题1-3

---
### 统计
- 总组数：N
- 总题数：M
- 建议用时：M × 45秒
- 涉及主题：[列出]
```
